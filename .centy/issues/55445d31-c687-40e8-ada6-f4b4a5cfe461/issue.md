# TUI: Add Edit Item Page

Add an edit item page to the TUI that allows users to edit existing items. This page should be reusable across different item types:

* Issues
* Docs
* PRs

## Requirements

* Create a unified edit page component that can handle different item types
* Support editing all relevant fields for each item type
* Provide a consistent user experience across item types
* Include validation for required fields
* Support saving changes and canceling edits

## Acceptance Criteria

* [ ] Edit page renders correctly for issues
* [ ] Edit page renders correctly for docs
* [ ] Edit page renders correctly for PRs
* [ ] Changes can be saved successfully
* [ ] Cancel action discards changes and returns to previous view
